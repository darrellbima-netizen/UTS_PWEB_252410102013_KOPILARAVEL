
Ngopi Dawg adalah aplikasi website coffee shop yang dikembangkan menggunakan framework Laravel sebagai proyek Ujian Tengah Semester (UTS) mata kuliah Pemrograman Web.

Aplikasi ini dirancang untuk mensimulasikan sistem pengelolaan coffee shop yang difungsikan untuk internal NgopiDawg sendiri bukan untuk umum. NgopiDawg memiliki beberapa halaman utama, yaitu Login, Dashboard, Pengelolaan, dan Profile.

Project ini menerapkan konsep MVC (Model-View-Controller) serta Blade Template Engine pada Laravel, termasuk penggunaan Blade Directives, Components, Request Handling, dan Array Rendering.

Fitur Utama
Login pengguna (simulasi).
Dashboard untuk menampilkan ringkasan informasi coffee shop.
Pengelolaan data menu dan bahan baku.
Halaman profil pengguna.
Navigasi antarhalaman.
